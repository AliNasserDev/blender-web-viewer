# Sample models

Committed here (license-safe):

- `default-cube-blender45.blend` — default cube scene saved from Blender 4.5.9 LTS (12 triangles, 1 point light, 1 camera)
- `knot.glb` — torus knot with rainbow vertex colors, generated by `scripts/make-sample-glb.mjs`

Everything else you see locally lives in `third-party/` (git-ignored). Re-download the well-known test set anytime:

```bash
npm run fetch:samples
```

Per-asset sources and licenses are listed in `scripts/fetch-samples.mjs`.
