# Sample models

Shippable demo assets live in [`../public/models/`](../public/models/) so they
deploy with the site:

- `default-cube-blender45.blend` — default cube scene saved from Blender 4.5.9 LTS (12 triangles, 1 point light, 1 camera)
- `knot.glb` — torus knot with rainbow vertex colors, generated by `scripts/make-sample-glb.mjs`

Well-known third-party test models (Khronos Duck/DamagedHelmet/Fox, Stanford
Bunny, three.js FBX/STL demos…) can be fetched locally:

```bash
npm run fetch:samples
```

They land in `third-party/` (git-ignored). Per-asset sources and licenses are
listed in `scripts/fetch-samples.mjs`.
